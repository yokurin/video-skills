# Prompt Templates & Examples

## 画像プロンプトテンプレート

```
[SUBJECT] A cute anthropomorphic {food_item} character with big expressive eyes, small arms and legs, 3D Pixar style
[ACTION] {scene_specific_action_and_expression}
[APPEARANCE] {food_item} body with cartoon face, {accessories_if_any}
[SETTING] {background_setting}, clean simple background
[LIGHTING] bright studio lighting, soft shadows, cheerful atmosphere
[COMPOSITION] full body centered, vertical 9:16 format
[STYLE] 3D rendered, Pixar-style animation, cute kawaii aesthetic
[QUALITY] 8k, highly detailed, vibrant colors, smooth rendering
```

### シーン別アクション例

| シーン | 表情・ポーズ | アクセサリー |
|--------|------------|------------|
| 1（フック） | crying dramatically, tears streaming, mouth wide open screaming | なし |
| 2（共感） | wiping tears, holding up one finger knowingly, slight smile | メガネ、指差し |
| 3（解決策） | pointing enthusiastically, excited expression, teaching pose | メガネ、ポインター |
| 4（結果） | victory pose, confident smirk, thumbs up, wearing sunglasses | サングラス、王冠 |

## 動画プロンプトテンプレート

各シーンの動きと声の感情を具体的に指示する。

```
{character_name} {motion_description}. Voice: "{dialogue}" spoken in {emotion} tone in Japanese.
```

### シーン別モーション例

| シーン | モーション | 声の感情 |
|--------|----------|---------|
| 1（フック） | shaking body, tears flying, dramatic crying motion | panicked, screaming, distressed |
| 2（共感） | calming down, wiping tears, raising finger with a knowing look | calm, secretive, whispering |
| 3（解決策） | pointing energetically, demonstrating the action | excited, enthusiastic, teaching |
| 4（結果） | jumping with joy, victory dance, confident pose | triumphant, proud, cheerful |
